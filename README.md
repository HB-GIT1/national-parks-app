# National Parks App

Route-first roadtrip planner for US national parks.

## Features
- Curated park loops (West Coast, Rockies, Desert)
- Build Mode for custom routes
- OSRM-based routing
- Google Maps / Apple Maps export
- URL-based route sharing (coming next)

## How to use
1. Open the map
2. Select a curated loop or build your own route
3. Export to Google/Apple Maps or share via link

## Tech
- 100% static (no backend)
- MapLibre GL JS
- OSRM routing
- GitHub Pages ready

## Deployment
This app runs fully static and can be deployed via GitHub Pages.
